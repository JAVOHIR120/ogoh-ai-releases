# Ogoh AI — chiqarilgan versiyalar

Ogoh AI — Oʻzbekiston uchun firibgarlikdan himoya ilovasi (Android 8.0+).
Bu yerda ilovaning har bir versiyasi APK fayl sifatida turadi.

**Yuklab olish sahifasi:** https://javohir120.github.io/ogoh-ai-releases/ (QR va yoʻriqnoma bilan).
**Doimiy APK havolasi:** https://github.com/JAVOHIR120/ogoh-ai-releases/releases/latest/download/ogoh-ai.apk

## Oʻrnatish
1. [Releases](https://github.com/JAVOHIR120/ogoh-ai-releases/releases/latest) sahifasidan `ogoh-ai-<versiya>.apk` ni yuklab oling.
2. Faylni oching. Android «Nomaʼlum manbalardan oʻrnatish»ga ruxsat soʻrasa, shu brauzer yoki fayl menejeri uchun ruxsat bering.
3. Oʻrnatilgach, ilova oʻzi yangilanishlarni tekshiradi: yangi versiya chiqqanda bildirishnoma keladi, Wi‑Fi'da oʻzi yuklab oladi va bir bosishda oʻrnatiladi.

## Yangilanish qanday ishlaydi
Ilova `releases/latest/download/update.json` faylini oʻqiydi (versiya, APK manzili, SHA‑256). APK yuklangach, xeshi tekshiriladi, keyin Android'ning oʻz oʻrnatish oynasi chiqadi.

## Установка (RU)
Скачайте `ogoh-ai-<версия>.apk` со страницы [Releases](https://github.com/JAVOHIR120/ogoh-ai-releases/releases/latest), откройте файл и разрешите установку. Дальше приложение обновляется само.
